# Human–AI Teaming Game

A browser-based, turn-based intercept game used as a human-subjects experiment on
how people work with AI teammates that behave in different ways.

A full README is coming soon.

## Run it locally

Requires Node 22.5 or newer. Nothing to install.

```sh
node server/app.js
```

Then open <http://localhost:3000/index.html>.
